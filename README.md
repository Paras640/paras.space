paras.space 🚀
Personal portfolio website of Paras Doshi — showcasing expertise in Cloud Infrastructure, Backend Engineering, Modern Web Development, and Artificial Intelligence & Machine Learning.

🌟 About This Project
paras.space is a modern, high-performance developer portfolio built to highlight my technical journey, professional projects, and hands-on experience across full-stack development, cloud systems, and machine learning architectures.

🛠️ Tech Stack & Architecture
Frontend & Web: Next.js / React / Astro, Tailwind CSS, TypeScript

Cloud & Infrastructure: AWS (Amazon Web Services), Docker, Cloudflare / Vercel (Hosting & DNS configuration)

Backend & APIs: Python, FastAPI, RESTful architectures

AI & Machine Learning: PyTorch, Hugging Face, LLM integrations (RAG pipelines)

Version Control & CI/CD: Git, GitHub Actions

💻 Getting Started Locally
If you want to run or inspect this portfolio locally on your machine:

Prerequisites
Node.js (LTS version) installed

Git installed

Installation Steps
Clone the repository:

Bash
git clone https://github.com/your-username/paras.space.git
cd paras.space
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Open your browser:
Navigate to http://localhost:3000 to view the site live.

🌐 Deployment
This site is continuously deployed via modern cloud-hosting infrastructure connected directly to this repository, ensuring fast global performance and automatic updates on every push.
